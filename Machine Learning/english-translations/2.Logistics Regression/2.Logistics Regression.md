## 1. What is Logistic Regression

Logistic regression is used for classification. We are all familiar with linear regression, whose general form is Y=aX+b, with y ranging over [-∞, +∞]. With such a wide range, how do we classify? No need to worry—mathematicians have already found a solution.

We feed the result Y into a **Sigmoid function** (a nonlinear transformation) to obtain a value S in [0,1]. S can be interpreted as a probability. If we set the probability threshold to 0.5, then S > 0.5 can be treated as a positive sample and S < 0.5 as a negative sample, enabling classification.

Whatever value t takes, the result lies in [0,1]. Recall that a binary classification problem has two outcomes: "yes" and "no." Then 0 corresponds to "no" and 1 to "yes." You might ask: isn't this the [0,1] interval? How can there be only 0 and 1? Good question. We assume the classification **threshold** is 0.5; then values above 0.5 are classified as 1 and below 0.5 as 0. The threshold can be set by the user.

The result P can also be interpreted as probability. In other words, probability > 0.5 belongs to class 1, and probability < 0.5 belongs to class 0, achieving the goal of classification.

## 3. What is the Loss Function

The loss function for logistic regression is **log loss**, i.e., the **log-likelihood function**:

![image](https://wx1.sinaimg.cn/large/00630Defly1g4pvtz3tw9j30et04v0sw.jpg)

In the formula, y=1 means use the first formula when the true value is 1, and use the second formula when the true y=0 to compute the loss. Why add the log function? Consider: when the true label is 1 but h=0 (probability), then log0=∞, imposing maximum penalty on the model; when h=1, then log1=0, i.e., no penalty and no loss, achieving the optimum. Mathematicians thus proposed using the log function to represent the loss.

Finally, as with gradient descent, we solve for the minimum and obtain the desired model.

## 4. Can It Perform Multi-class Classification?

Yes. We can extend from binary to multi-class (one vs rest) as follows:

1. Treat class1 as the positive class and all other classes as negative, and compute the probability p1 that the sample belongs to this class.
2. Treat class2 as the positive class and all others as negative, and compute p2.
3. Repeat to obtain pi for each class i.
4. Take the class with the largest pi as the predicted class for the sample.

![image](https://wx2.sinaimg.cn/large/00630Defly1g4pw11fo1tj30cv0c50tj.jpg)

In short, we repeatedly apply binary classification and take the class with the maximum probability.

## 5. What Are the Advantages of Logistic Regression

- LR outputs probabilities rather than just 0/1 labels.
- LR is interpretable and controllable (useful when explaining to stakeholders).
- Fast to train; performs well after feature engineering.
- Because outputs are probabilities, it can serve as a ranking model.

## 6. What Are the Applications of Logistic Regression

- CTR prediction / learning to rank in recommendation systems / various classification scenarios.
- A major search engine uses LR as the baseline for ad CTR prediction.
- E-commerce search ranking / ad CTR baseline uses LR.

## 7. What Optimization Methods Are Commonly Used for Logistic Regression

### 7.1 First-Order Methods

Gradient descent, stochastic gradient descent, mini-batch stochastic gradient descent. Stochastic gradient descent is not only faster than plain gradient descent but also helps avoid local optima to some extent.

### 7.2 Second-Order Methods: Newton's Method, Quasi-Newton Method

Newton's method: it iteratively updates the tangent's intersection with the x-axis until reaching the intersection of the curve with the x-axis (the solution). In practice we often solve convex optimization problems, i.e., finding where the first derivative is 0. Newton's method naturally fits this. It picks a starting point and does a second-order Taylor expansion to find the point where the derivative is 0, then updates until convergence. So Newton's method becomes a second-order solver and is faster than first-order methods. Often x is a multi-dimensional vector, which leads to the Hessian matrix (the second derivative matrix of x).

**Drawbacks**: Newton's method uses a fixed step size (no step factor), so it does not guarantee stable decrease in the objective; in severe cases it can fail. It also requires the function to be twice differentiable. Computing the inverse of the Hessian can be expensive.

**Quasi-Newton method**: Instead of second-order derivatives, it constructs an approximate positive-definite symmetric matrix for the Hessian. The idea is to approximate the Hessian (or its inverse) with a special form that satisfies the quasi-Newton condition. Main variants: DFP (approximates the inverse of the Hessian), BFGS (approximates the Hessian directly), L-BFGS (reduces storage compared to BFGS).

## 8. Why Does Logistic Regression Require Feature Discretization

1. **Nonlinearity!** Logistic regression is a generalized linear model with limited expressiveness. Discretizing a variable into N bins gives each bin its own weight, effectively introducing nonlinearity and improving expressiveness.
2. **Speed!** Sparse vector inner products are fast; results are easy to store and extend.
3. **Robustness!** Discretized features are robust to outliers. E.g., age>30 is 1, else 0. Without discretization, an outlier like "age 300" would severely distort the model.
4. **Feature interaction**: After discretization we can form feature crosses, expanding M+N variables to M*N, introducing more nonlinearity.
5. **Stability**: After discretization, the model is more stable. E.g., ages 20–30 in one bin will not change labels with small age shifts. (Though samples near bin boundaries may flip—binning is an art.)
6. **Simplicity**: Discretization simplifies the model and reduces overfitting risk.
