## 1. Differences: Markov Network, Markov Model, Markov Process, Bayesian Network

Assume you understand Bayesian networks (see [5.1 Bayes Network](../5.1%20Bayes%20Network/5.1%20Bayes%20Network.md)).

Six points, in order:

1. Represent random variables as nodes; connect two variables if they are dependent. Given variables, form a graph—a **network**.
2. If the graph is a DAG, it is a **Bayesian network**.
3. If the graph degenerates to a linear chain, we get a **Markov model**; as a random process over time/space, it is a **Markov process**.
4. If the graph is undirected, it is an undirected graphical model—a **Markov random field** or **Markov network**.
5. Under conditioning on some variables, we obtain a **conditional random field**.
6. For sequence labeling, if the CRF graph is linear, we get a **linear-chain CRF**.

## 2. Markov Model

### 2.1 Markov Process

A Markov process is a type of stochastic process (Markov chain, by A.A. Markov, 1907). Key property: **Given the current state, the future is independent of the past.** Examples: animal population in a forest, Brownian motion, infected count, queue length.

When each state transition depends only on the previous n states, it is an n-th order model. The simplest is first-order: **each state depends only on the previous state**—the **Markov property**:

![](https://latex.codecogs.com/gif.latex?P(X_{n+1}|X_1=x_1,X_2=x_2,...,X_n=x_n)=P(X_{n+1}=x|X_n=x_n))

**Weather example (Markov chain)**:

![](http://wx4.sinaimg.cn/mw690/00630Defly1g4y8tb8xekj30b602z74n.jpg)

- If today is sunny, P(cloudy tomorrow) = 0.1, P(sunny tomorrow) = 0.9.
- Transition matrix:

|        | Sunny | Cloudy |
| ------ | ----- | ------ |
| **Sunny**  | 0.9   | 0.1    |
| **Cloudy** | 0.5   | 0.5    |

First-order Markov process components:
- **States**: Sunny, Cloudy
- **Initial distribution**: P(state at t=0)
- **Transition matrix**: P(next state | current state)

Markov models are widely used in speech recognition, POS tagging, and NLP.

## 3. Hidden Markov Model (HMM)

Sometimes we cannot observe the true state. In the weather example, a hermit observes seaweed instead of weather. Seaweed state is probabilistically related to weather. We have observable states (seaweed) and hidden states (weather). We want to infer weather from seaweed—that is **HMM**.

![](http://wx3.sinaimg.cn/mw690/00630Defly1g4yaq7ndgij30nd0c9mzy.jpg)

An HMM is a statistical model for a Markov process with hidden parameters. It is the simplest dynamic Bayesian network (directed). Used for sequential data in speech recognition and NLP.

### 3.1 Three Core Problems of HMM

1. **Evaluation**: Given the model, compute P(observation sequence).
2. **Decoding**: Given model and observations, find the most likely hidden state sequence.
3. **Learning**: Given observations, estimate model parameters (π, A, B) to maximize P(observations).

Solutions:
1. Forward algorithm, Backward algorithm
2. Viterbi algorithm
3. Baum-Welch algorithm (≈ EM)

**Example**: Xiaoming has a 3-day holiday. Each day he can walk, shop, or clean (observations). His choices depend on weather (sunny, rainy—hidden). Given the model and observations (walk, shop, clean), we ask:
1. What is P(observations)?
2. What was the weather each day?
3. Given only observations, estimate the model.

#### 3.1.1 Problem 1: Evaluation

**Brute-force**: Enumerate all hidden paths, sum probabilities. Complexity O(2T N^T).

**Forward algorithm**: Build alpha(t) recursively; complexity O(N²T). Similar to dynamic programming.

**Backward algorithm**: Same idea, working backward from the last time step.

#### 3.1.2 Problem 2: Decoding

**Viterbi algorithm**: A dynamic programming algorithm for finding the most likely hidden path. Used in digital communications, speech recognition, machine translation, pinyin-to-character, word segmentation.

Given observations (walk, shop, clean), find the most likely weather sequence. At each step, compute the best path ending at each state; keep track of the path. The path with highest final probability is the answer (e.g., Sunny → Sunny → Rainy).

For details, see "The Beauty of Mathematics" Ch. 26.

#### 3.1.3 Problem 3: Learning

Baum-Welch algorithm (≈ EM). See [Supervised Learning and Baum-Welch](https://blog.csdn.net/qq_37334135/article/details/86302735).

## 4. Markov Network

### 4.1 Factor Graph

A factor graph factorizes a global function into a product of local functions. It has variable nodes and function nodes. Marginal inference can be done efficiently with the sum-product algorithm.

### 4.2 Markov Network

A directed graph (Bayesian network) requires directed edges. In some cases direction is inappropriate. **Undirected edges form an undirected graphical model (UGM)**—a **Markov random field (MRF)** or **Markov network**.

When Y forms an MRF and we condition on X, P(Y|X) is a **conditional random field (CRF)**. A linear-chain CRF is commonly used for sequence labeling.

## 5. Conditional Random Field (CRF)

**Intuition**: You have photos of Xiaoming at different times. Task: label each photo (eating, running, meeting). A simple approach: train a classifier on features only, ignoring order. But order matters. E.g., a photo of Xiaoming with mouth closed—eating or singing? You need the previous photo. **CRF incorporates neighboring labels** when classifying each position. This is like POS tagging: use context.

CRF is an undirected graphical model. Nodes are random variables; edges capture dependence. P(Y|X) is the CRF.

## 6. Comparison: EM, HMM, CRF

1. **EM**: For models with latent variables; MLE/MAP. E-step: expectation; M-step: maximization. Iterative; sensitive to initialization; **no guarantee of global optimum**. Used to derive many algorithms.

2. **HMM**: Generative model for labeling. Parameters: π (initial), A (transition), B (emission). Three problems: evaluation (forward/backward), learning (Baum-Welch ≈ EM, MLE), decoding (Viterbi, greedy approximation).

3. **CRF**: Models P(output | input). Output forms an MRF; linear-chain CRF is common. Discriminative. Learning: MLE or regularized MLE. Similar structure to HMM but no EM for learning.

4. **HMM vs. CRF**: HMM uses a directed graph (Bayesian network); CRF uses an undirected graph (MRF). HMM is generative; CRF is discriminative. Both have evaluation, learning, and decoding, but CRF does not need EM.
