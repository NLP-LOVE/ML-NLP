## 1. What is KNN

**K-Nearest Neighbors (KNN)**: For a new instance, find the K nearest training points and assign the majority class. Distance metrics: Euclidean, Manhattan, Minkowski, etc. Choose K via cross-validation.

## 2. KD-Tree Implementation

KD-tree partitions space for efficient nearest-neighbor search. Build, insert, delete, and search operations. BBF improves search when dimensions are high.

## 3. KNN Questions

Q: Why Euclidean distance in K-means/KNN instead of Manhattan?
A: Euclidean works in any space; Manhattan is limited to axis-aligned distances.
