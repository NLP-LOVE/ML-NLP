### Project: Handwritten Digit Recognition System

[Full Code](https://github.com/NLP-LOVE/ML-NLP/blob/master/Machine%20Learning/9.%20KNN/handwritingClass/handwritingClass.py)

#### Overview

Build a KNN-based handwritten digit recognition system for digits 0–9. Digits are stored as 32×32 pixel black-and-white images in text files.

#### Development Flow

1. **Collect data**: Text files.
2. **Prepare data**: `img2vector()` – convert images to vectors.
3. **Analyze data**: Inspect data in Python.
4. **Train**: Not applicable for KNN.
5. **Test**: Use a subset as test set; compare predicted vs. actual labels.
6. **Use**: Build a full app (e.g., mail sorting system).

**Data:** [trainingDigits.zip](https://github.com/NLP-LOVE/ML-NLP/blob/master/Machine%20Learning/9.%20KNN/handwritingClass/trainingDigits.zip) (~2000 examples), [testDigits.zip](https://github.com/NLP-LOVE/ML-NLP/blob/master/Machine%20Learning/9.%20KNN/handwritingClass/testDigits.zip) (~900 test samples). Download and extract.

> Project source: [apachecn/AiLearning](https://github.com/apachecn/AiLearning) (K-Nearest Neighbors)
