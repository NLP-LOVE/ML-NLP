## 1. Explain the GBDT Algorithm Process

GBDT (Gradient Boosting Decision Tree) uses **Boosting**.

### 1.1 Boosting Idea

Boosting trains base learners sequentially; each depends on the previous ones. Each new learner is trained with higher weight on samples the previous ones got wrong. At test time, results are combined by weighted voting. Unlike Bagging, Boosting is sequential and not parallel.

### 1.2 What GBDT Really Is

GBDT sums the outputs of weak learners to get the prediction. Each new weak learner fits the residual (error between prediction and target). The weak learners are trees.

**Simple example**: I am 30 years old; the model doesn’t know that.

- Tree 1 predicts 20; residual = 10.
- Tree 2 fits the residual, predicts 6; residual = 4.
- Tree 3 predicts 3; residual = 1.
- Tree 4 predicts 1; residual = 0.
- Sum: 20+6+3+1 = 30. (In practice, GBDT uses negative gradients to approximate residuals.)

**Why can GBDT use negative gradients to approximate residuals?**

For regression with MSE loss, the negative gradient equals the residual. So fitting the negative gradient is equivalent to fitting the residual. The “variable” being updated is the current prediction.

**Training process**: With 4 people A,B,C,D aged 14,16,24,26, GBDT fits residuals step by step. Each new tree fits the residuals of the previous ensemble until residuals are driven to zero.

So: GBDT accumulates scores from multiple trees; each iteration adds a tree that fits the residual between the current prediction and the true value.

## 2. Relationship Between Gradient Boosting and Gradient Descent

Both use the negative gradient of the loss w.r.t. the model to update the model each iteration. In gradient descent, the model is parameterized, so updates are parameter updates. In gradient boosting, the model lives in function space and is not explicitly parameterized, which allows more flexible model forms.

## 3. Pros and Limitations of GBDT

### 3.1 Pros

1. Fast prediction; trees can be evaluated in parallel.
2. Strong generalization and expressiveness on dense data; GBDT often ranks top in Kaggle.
3. Decision trees as weak learners provide interpretability and robustness; GBDT can capture high-order feature interactions.

### 3.2 Limitations

1. On high-dimensional sparse data, GBDT usually underperforms SVM or neural networks.
2. For text classification, GBDT’s advantage over other models is less pronounced than for numerical features.
3. Training is sequential; only limited parallelism inside trees is possible.

## 4. RF vs. GBDT

**Similarities:**

- Both use multiple trees; final output is determined by all trees.
- Both can use CART trees (classification or regression).

**Differences:**

- RF trains trees in parallel; GBDT trains sequentially.
- RF uses majority voting; GBDT sums tree outputs.
- RF is robust to outliers; GBDT is sensitive.
- RF reduces variance; GBDT reduces bias.
- RF does not need feature normalization; GBDT does.
