## 1. What is XGBoost

XGBoost is an open-source ML project developed by Tianqi Chen et al. It implements GBDT efficiently with many algorithmic and engineering improvements and is widely used in Kaggle and other ML competitions.

XGBoost is essentially GBDT but optimized for speed and efficiency—hence "X" for Extreme. Both are boosting methods.

For GBDT background, see [3.2 GBDT](../3.2%20GBDT/3.2%20GBDT.md).

### 1.1 XGBoost Tree Definition

**Example**: Predict a family’s interest in video games. Young people tend to like games more than elders; males more than females. We split by age first (child vs. adult), then by gender, and assign scores accordingly.

Training yields tree1 and tree2. As in GBDT, we sum their outputs. A child’s score = sum of leaf scores in both trees (e.g., 2 + 0.9 = 2.9). An elder’s score: -1 + (-0.9) = -1.9.

The main difference from GBDT is the **objective function**. XGBoost’s objective includes:
- Loss (e.g., squared loss)
- Regularization (L1, L2)
- Constant terms
- Taylor expansion (up to second order) of f(x), where f(x) is one regression tree

Core algorithm:
1. Add trees iteratively; each new tree learns to fit the residual of the previous ensemble.
2. For prediction, each sample falls into a leaf in each tree; each leaf has a score.
3. Sum the leaf scores across trees to get the final prediction.

We want predictions close to true values and good generalization. As in GBDT, we add trees that fit the residual. We choose each new f to minimize the objective; Taylor expansion is used for approximation.

The optimization is over which leaf each sample goes to; different leaf assignments give different objectives. We also add a regularization term for tree complexity.

### 1.2 Regularization: Tree Complexity

XGBoost regularizes tree complexity via:
- Number of leaves T
- L2 norm of leaf scores w (smoothing to reduce overfitting)

Objective = loss + regularization. The regularization term penalizes complexity; smaller values mean better generalization.

### 1.3 How Does the Tree Grow

Trees grow by splitting nodes. XGBoost uses a **greedy enumeration** over tree structures: enumerate splits, score them, pick the best, and add to the model. The scoring function uses the objective. As with CART, we search over features and split points; the difference is the objective. We only split when the gain exceeds a threshold (to limit depth). **Each iteration adds the best possible split on top of the current ensemble.**

### 1.4 When to Stop Growing Trees

1. **Gain threshold**: If the gain from a split is below a threshold, ignore it (pre-pruning).
2. **Max depth**: Stop when the tree reaches max_depth to avoid overfitting.
3. **Min child weight**: If a leaf has too few samples (by weight), stop splitting.

## 2. How XGBoost Differs from GBDT

1. GBDT is the algorithm; XGBoost is an engineered implementation.
2. XGBoost adds explicit regularization to control complexity and reduce overfitting.
3. GBDT uses only first-order derivatives; XGBoost uses first- and second-order (Taylor expansion).
4. XGBoost supports multiple base learners (e.g., linear models), not just CART.
5. GBDT uses all data each iteration; XGBoost supports row/column sampling like Random Forest.
6. GBDT has no built-in missing-value handling; XGBoost learns how to handle missing values automatically.

## 3. Why Does XGBoost Use Taylor Expansion? What Are the Advantages?

Using first- and second-order derivatives allows faster, more accurate optimization. Taylor expansion gives a second-order approximation of the loss, so we can optimize leaf splits without committing to a specific loss form. The loss choice is decoupled from the optimization. XGBoost can thus support different losses (classification, regression) flexibly.
