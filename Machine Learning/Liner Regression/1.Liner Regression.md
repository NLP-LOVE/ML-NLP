## 1. What is Linear Regression

- **Linear**: The relationship between two variables **is** a first-degree function relationship—the graph **is a straight line**—called linear.
- **Nonlinear**: The relationship between two variables **is not** a first-degree function relationship—the graph **is not a straight line**—called nonlinear.
- **Regression**: When measuring things, people obtain measured values rather than true values due to objective constraints. To obtain the true value, they perform measurements infinitely many times and then **regress to the true value** through these measurement data—this is the origin of the term "regression."

## 2. What Kind of Problems Can It Solve

Process a large amount of observational data to obtain mathematical expressions that better conform to the internal laws of the phenomena. That is, find the patterns between data points so as to simulate outcomes and predict results. The problem solved is obtaining unknown results from known data. Examples: house price prediction, credit evaluation, movie box office estimation, etc.

## 5. How to Address Overfitting and Underfitting

Use regularization terms, i.e., add a parameter term to the loss function. Regularization terms include **L1 regularization, L2 regularization, and ElasticNet**. Benefits of adding regularization:

- Control parameter magnitude so the model does not go "uncontrolled."
- Limit the parameter search space
- Address both underfitting and overfitting.

### 5.1 What is L2 Regularization (Ridge Regression)

Equation:

![](https://latex.codecogs.com/gif.latex?J=J_0+\lambda\sum_{w}w^2)

![](https://latex.codecogs.com/gif.latex?J_0) denotes the loss function above; we add the sum of squares of the w parameters multiplied by ![](https://latex.codecogs.com/gif.latex?\lambda). Suppose:

![](https://latex.codecogs.com/gif.latex?L=\lambda({w_1}^2+{w_2}^2))

Recall the equation of the unit circle:

![](https://latex.codecogs.com/gif.latex?x^2+y^2=1)

This is exactly like the L2 regularization term. Our task becomes finding the solution that minimizes J under the L constraint. The process of solving J0 can be visualized with contour lines. Meanwhile, the L2 regularization function L can also be plotted in the w1-w2 plane. See the figure below:

![image](https://wx4.sinaimg.cn/large/00630Defgy1g4ns9qha1nj308u089aav.jpg)

L is represented by the black circle in the figure. As gradient descent keeps approaching, the first intersection with the circle occurs, and this intersection rarely falls on the coordinate axes. This shows that L2 regularization tends not to yield sparse matrices; meanwhile, to minimize the loss function, it makes w1 and w2 infinitely close to 0, achieving the effect of preventing overfitting.

### 5.2 When to Use L2 Regularization

When data is linearly correlated and LinearRegression does not fit well—**regularization is needed**—consider Ridge Regression (L2). However, if the input feature dimension is high and the linear relationship is sparse, Ridge Regression is less suitable; consider Lasso Regression instead.

### 5.3 What is L1 Regularization (Lasso Regression)

The difference between L1 and L2 regularization lies in the penalty term:

![](https://latex.codecogs.com/gif.latex?J=J_0+\lambda(|w_1|+|w_2|))

The process of solving J0 can be visualized with contour lines. The L1 regularization function can also be plotted in the w1-w2 plane. See the figure below:

![image](https://ws2.sinaimg.cn/large/00630Defgy1g4nse7rf9xj308u089gme.jpg)

The penalty term is represented by the black diamond in the figure. As gradient descent keeps approaching, the first intersection with the diamond occurs, and this intersection often falls on the coordinate axes. **This shows that L1 regularization tends to yield sparse matrices.**

### 5.4 When to Use L1 Regularization

**L1 regularization (Lasso Regression) can shrink some feature coefficients and even drive smaller absolute coefficients directly to 0**, thus enhancing model generalization. For high-dimensional feature data, especially when the linear relationship is sparse, use L1 regularization (Lasso Regression). If you need to identify the main features among many, L1 regularization (Lasso Regression) is the preferred choice.

### 5.5 What is ElasticNet Regression

**ElasticNet combines the L1 and L2 regularization terms**. Its formula is:

![](https://latex.codecogs.com/gif.latex?min(\frac{1}{2m}[\sum_{i=1}^{m}({y_i}^{'}-y_i)^2+\lambda\sum_{j=1}^{n}\theta_j^2]+\lambda\sum_{j=1}^{n}|\theta|))

### 5.6 Use Cases for ElasticNet Regression

Consider ElasticNet Regression when Lasso is too aggressive (too many features are sparsified to 0) and Ridge does not regularize enough (regression coefficients decay too slowly). ElasticNet combines both to yield better results.

## 6. Does Linear Regression Require the Dependent Variable to Follow a Normal Distribution?

We assume the noise in linear regression follows a normal distribution with mean 0. When the noise follows N(0, delta^2), the dependent variable follows N(ax(i)+b, delta^2), where the prediction function is y=ax(i)+b. This conclusion can be derived from the probability density function of the normal distribution. That is, when the noise follows a normal distribution, the dependent variable necessarily also follows a normal distribution.

Before fitting data with a linear regression model, the data should first conform to or approximately conform to a normal distribution; otherwise, the resulting fit will be incorrect.
